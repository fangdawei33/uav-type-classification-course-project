# 论文组织与图表安排

本次参考用户提供的八页长视频理解论文与科研汇报截图，只借鉴问题、方法、实验和证据的组织方式。未将参考稿、截图、他人图片或他人的数值复制进本项目，也不把截图中的投稿或录用信息当作已核实依据。

参考稿的正文顺序为 Introduction、Related Work、Method、Experiments and Analysis、Conclusion。实验依次包含 Experimental Setup、Main Results、Ablation Studies、Qualitative Analysis、Discussion。其图表分别承担问题示意、方法框架、策略比较、组件分析、参数敏感性、类别或领域表现、样例解释等职责。参考稿仍有未解析的交叉引用占位符，因此不是可直接照搬的定稿模板。

本项目保留课程要求的八章，内部采用以下论证顺序：

| 章节 | 回答的问题 | 证据 |
| --- | --- | --- |
| 1 实验概述 | 研究什么、为什么比较这三条路径 | 三个研究问题与图1 |
| 2 相关原理 | 使用的方法与指标是什么 | 爬虫、传统模型、视觉表示、QLoRA、交叉验证原理 |
| 3 设计与实现 | 数据怎样获取、处理、隔离并训练 | 原始记录、清洗前后对比、代码节选、图2 |
| 4.1 数据统计 | 实际能评价哪些类别与尺度 | 类别表与图3 |
| 4.2 总体结果 | 相同测试集上哪种设置表现怎样 | 十三组结果与图4 |
| 4.3 参数分析 | 网格如何选参、调优是否带来测试收益 | 参数表、验证波动、图5 |
| 4.4 适配对照 | 微调和类别加权分别有什么观察结果 | 零样本/标准/加权对比与真实训练日志，图6 |
| 4.5 分类错误 | 均值背后是哪几类混淆 | 图7、图8、固定规则选择的预测样例 |
| 5 分析与讨论 | 误差可能来自哪里、证据能说明到什么程度 | 特征解释、尺度分层、过拟合诊断，图9、图10 |
| 6至8 | 问题如何处理、课程思考与后续改进 | 实际报错、四道思考题、总结与局限 |

十组图使用统一字体、固定方法配色和简短标签；比较图共享指标口径，混淆矩阵按真实类别归一化且保留全部预测类别。原始CSV与JSON不因绘图而改变。绘图模块为 `src/uav_project/paper_figures.py`，入口为 `scripts/17_complete_course_report.py --refresh-figures`，不调用分类器、不启动模型推理或训练。

不能套用的内容包括：没有实测的模块消融、没有固定验证集却绘制验证曲线、没有同环境基准却比较跨模型延迟、没有特征矩阵却画虚构t-SNE，以及把不同数据规模和不同任务的结果写成可比的跨数据集泛化实验。现有Qwen对照仅检验已执行的适配设置，尺度分层属于事后诊断，均不支持完整模块因果结论。

图表不直接复用参考稿的装饰边框或PPT色块。本文采用适合打印的白底、克制配色与三线表；PDF示例为双栏论文，课程报告需要容纳代码、过程记录和八章要求，因此保留单栏。当前版文件为 `final_report_paper.docx`，旧Word文件因用户正在打开而保留为历史版本。
