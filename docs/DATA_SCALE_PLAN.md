# 数据规模目标与扩采优先级

更新：2026-10-22。本文是项目采集目标和可行性检查计划，不是已取得数量或期刊发表门槛。对应机器可读文件：configs/data_scale_plan.json；不自动改变现有下载配额或实验开关。

当前公开作者数据2973张，2720张通过视觉候选筛选；这是现有开发数据候选，尚未完成来源准入和正式划分。自采集为165候选/125视觉暂留/32待定/8排除，另6张参考图不进入实验候选。63张新增图完成接触表筛选，14张另看原图，尚非所有原图精审或最终准入。现有来源不足，不能把这批试采描述为已完成的七类外部测试集。

此前Commons每类上限30是试采参数，不是源站数据总量。后续实际遍历已配置类别及分页，取得Bebop 44、Phantom 3 67、Phantom 4 Pro 48条不同栅格文件页链接，共159条；下载后保留146张候选，不能将格式/体积失败计为有效图片。来源清单见outputs/source_inventory/commons_inventory_current.json。单纯改上限不能保证每类有100张。

正式外部集的项目目标先设为每类100张合格图片、争取200张，即七类700—1400张，并争取每类至少5个经核对的独立拍摄来源。上述数值须先验证可达性，数量本身不保证评估可靠。来源按原作者/拍摄批次/原始视频及证据判断，不按网站/URL计数。图像增强、同图转载和近邻抽帧不能虚报为新增独立采样。

优先核查Intel Aero RTF、Emax、Mambo、YH 19Hw：当前分别只有1、4、10、4张（Mambo新增七张为6暂留/1排除），Intel一张仍待定。先按原始机型身份和出处建立可下载候选清单，统计候选页数、可辨目标、原图数、已知重复、可能独立来源、下载权限/失败，不先批量下载大量来源相同或身份不明的图片。

Commons前三类随后在已配置类别中续采，避免只增加这些类别使不平衡更严重。来源可行性表需明确已核实与未知；若稀缺类别确实不支持目标规模，先记录并提出调整公开基准或类别范围的方案，保留现有数据，不静默换题、不把检测数据当机型分类标签。

当前尚未修改类别范围；本轮Commons新增56张、文章新增7张候选，尚无模型训练、评估或软件测试。多平台调查已执行，FRED/Cranfield/Kaggle的适配限制与训练合成方案见research/platform_datasets_and_synthetic_2026-10-22.md；精细标注和论文结果部分不能掩盖数量与来源缺口。
