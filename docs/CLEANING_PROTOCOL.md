# 七类目标区域分类清洗协议

版本：visual-primary-cohort-v1-2026-10-22。协议及全部视觉决定在任何训练和模型分数产生前记录；后续修改必须保存新版本、原因和证据。

## 任务与输入

主输入target_crop：从原始图片按核查后的标注框裁剪，不能将画有红框/文本的审核预览当作模型输入。所有比较方法声明相同输入范围。作者真值框是额外监督，任务为给定区域七类分类；不声称自动目标检测。外部照片需要同一协议的独立目标框审核。

## 决定含义

review.csv的keep表示视觉候选，reject表示按明确理由排除，pending表示未决。当前2973张为2720 keep、253 reject、0 pending。作者类别仍未独立鉴定。AI辅助视觉审核不写成两名人工独立标注。

keep不自动获得来源ID。正式04 --apply仍检查保留图有带证据的confirmed来源组、审核group_id匹配、原图和标注哈希、方向、选框与证据。当前来源确认0组，不能执行正式应用。

## 统一的主实验排除规则

1. 标注框指向背景、停机坪、画中画中的错误对象或可拆配件，或错误裁剪遗漏大部分主机身；不把这种情况写成“原图没有无人机”。
2. 机身在画外，仅剩桨叶、护罩或部件；原生像素仍不足以确认目标内容的YH210也排除，不凭放大编造细节。
3. 目标区域内烧录的检测框/置信度、画中画边界、后期型号/来源字幕、渲染传感锥/航迹等。区分模型答案字幕与来源致谢字幕。
4. 明显交叉淡化/双重曝光污染目标。低曝光或低对比度本身不等于转场。
5. 宣传标题卡域按当前真实场景实验范围排除；部分标题在框外，不能一概写成框内答案泄露。宣传蒙太奇中的其他真实目标画面不因此全部排除。
6. 完全重复冗余单独记录；Phantom 4 Pro 139—141与138完全重复。本轮138也因标题卡域排除，保留重复事实而不补回138。

物体自带品牌铭牌与后期字幕分别标记。仅在框外有字幕不自动排除（标题卡域规则除外）。目标机身仍可辨认的小、模糊、逆光、遮挡和局部自然截断保留为困难候选；不按未来模型得分删难图。不使用生成式补图或去字幕后将结果冒充原始实拍。

## 多框处理

原TXT不覆盖，不默认选择最大框。记录原标注非空行从0开始的selected_box_index、选择理由、审核者、图片/标注/证据哈希。reviewed才能应用，proposed不能用。23张多框图中22项reviewed，YH210一项proposed且该图已排除。每图至多输出一个分类候选；若今后采用多实例方案，需另定单位和划分协议。
